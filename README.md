# Digital Portfolio - Mr. X
Inlämningsuppgift i kursen GIK32J. En digital portfolio byggd för den fiktiva profilen Mr. X.

## Sidor
-`index.html`- Startsida (Om mig)
-`kompetenser.html` - Kompetenser och färdigheter
-`projekt.html` - Tidigare projekt
-`utbildning.html` - Utbildning och kurser
-`referenser.html` - Referenser och omdömen
-`kontakt.html` - Kontaktformulär
-`tack.php` - Bekräftelsesida som tar emot data från formuläret

## Övriga filer
-`css/style.css` - Styling skriven med BEM
